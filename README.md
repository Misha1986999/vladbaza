# ВладБаза — доска объявлений Владивостока (MVP)

Стек: React + Vite + Tailwind CSS + Supabase.

## Что уже сделано

- Каталог объявлений с фильтром по категории, району и поиском
- Страница объявления с фото и кнопкой "Показать телефон"
- Форма публикации объявления (с загрузкой фото) — только для авторизованных
- Регистрация / вход
- Админ-панель модерации `/admin` (одобрить / отклонить объявление)
- Просмотр объявлений открыт всем, публикация — только зарегистрированным

## Шаг 1. Создать проект в Supabase

1. Зайдите на [supabase.com](https://supabase.com), создайте бесплатный аккаунт и новый проект.
2. Дождитесь, пока проект создастся (1-2 минуты).
3. Слева откройте **SQL Editor** → **New query**, вставьте целиком содержимое файла
   `supabase/schema.sql` из этого проекта и нажмите **Run**.
4. Слева откройте **Storage** → **Create a new bucket**:
   - Имя: `listing-photos`
   - Public bucket: **включить**
5. После создания bucket откройте его → **Policies** → добавьте политику, разрешающую
   публичное чтение (`select`) для всех и загрузку (`insert`) для авторизованных
   пользователей — в файле `supabase/schema.sql` внизу есть готовые команды
   (раскомментируйте и выполните в SQL Editor).

## Шаг 2. Подключить проект к вашей базе

1. В Supabase откройте **Project Settings → API**.
2. Скопируйте **Project URL** и **anon public key**.
3. В этом проекте скопируйте файл `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
4. Впишите в `.env` скопированные значения.

## Шаг 3. Установить зависимости и запустить

Понадобится [Node.js](https://nodejs.org) (версия 18 или новее).

```bash
npm install
npm run dev
```

Откройте адрес, который покажет терминал (обычно `http://localhost:5173`).

## Шаг 4. Сделать себя администратором

1. Зарегистрируйтесь на сайте через обычную форму регистрации.
2. В Supabase откройте **Table Editor → profiles**, найдите свою строку по email
   (или посмотрите **Authentication → Users** чтобы найти свой `id`).
3. В колонке `is_admin` поставьте `true`.
4. Теперь вам доступна страница `/admin` для модерации объявлений.

## Публикация сайта (бесплатно)

1. Загрузите этот проект в GitHub (создайте репозиторий и запушьте код).
2. Зайдите на [vercel.com](https://vercel.com), подключите GitHub-репозиторий.
3. В настройках проекта на Vercel добавьте переменные окружения
   `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (те же значения, что в `.env`).
4. Нажмите Deploy — через минуту сайт будет доступен по ссылке вида
   `vladbaza.vercel.app`. Позже можно подключить свой домен.
